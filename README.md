# Calendly homepage recreation

Run `node server.cjs` from this folder, then open http://127.0.0.1:4173. Node.js is required.

Includes the full public homepage layout, local fonts, illustrations, Rive animations, responsive navigation, product tabs, feature accordions, customer stories and footer.

This is an independent frontend recreation, not Calendly source code or its signed-in application. Other marketing pages, signup and account links lead to calendly.com. No account data is collected here.

The original layout, brand, fonts and artwork belong to their respective owners. Rive runtime license is included in dist/assets/LICENSE.
